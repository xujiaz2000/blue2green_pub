# BF16：CANN、Model Runner 与 CPU 绑核的独立对比

**当前 BF16 观测中，MRV2 的吞吐提升最明显；CANN 9.2 在全部已测条件下均略低于 9.1；关闭绑核没有带来一致改善。**

本报告分析已完成的 14 组 BF16 正式测试，不包含 W8A8，也没有新增测试。吞吐取 AISBench Common Metric 的 Output Token Throughput，单位 token/s。原始单轮与三轮复测分别展示；三个维度的变化都以指定基准计算。

## 1. CANN 9.2 相对 CANN 9.1

保持相同 Runner 和绑核状态；变化 = CANN92 / CANN91 − 1。

| 条件与样本数 | CANN 9.1.0 | CANN 9.2.0 | 变化 |
| --- | ---: | ---: | ---: |
| MRV1，开绑核（n=1） | 781.8579 | 769.1510 | **-1.63%** |
| MRV1，关绑核（n=1） | 782.0327 | 770.0517 | **-1.53%** |
| MRV2，开绑核，原单轮（n=1） | 800.3532 | 799.0187 | **-0.17%** |
| MRV2，开绑核，三轮均值（n=3） | 807.1498 | 801.2234 | **-0.73%** |
| MRV2，关绑核（n=1） | 805.5155 | 795.8386 | **-1.20%** |

MRV2 开绑核的三次复测中，CANN92 每次均较低，差距为 **0.48%–0.94%**；三轮均值之比为 **-0.73%**。这个差异方向在本批三轮中一致，但仍不能仅凭整轮吞吐确认 CANN 内部的唯一性能根因。跨 CANN 比较的是对应 CANN 软件栈，包括其附带包和工具。

## 2. MRV2 相对 MRV1

保持同一 CANN 和绑核状态；变化 = MRV2 / MRV1 − 1。

| CANN | 开绑核：原单轮 MRV2 / 原单轮 MRV1 | 开绑核：MRV2 三轮均值 / 原单轮 MRV1 | 关绑核：单轮 MRV2 / 单轮 MRV1 |
| --- | ---: | ---: | ---: |
| 9.1.0 | **+2.37%** | **+3.23%** | **+3.00%** |
| 9.2.0 | **+3.88%** | **+4.17%** | **+3.35%** |

所有观测对比均显示 MRV2 更快，量级约 **2.37%–4.17%**。MRV1 每个条件只有一次，MRV2 三轮均值与它的对比是 n=3 对 n=1，不能当作三组交错配对实验。

CANN92 下，MRV1 开/关绑核的两次吞吐均低于 BF16 原 CI 下限 **778.365054 token/s**；MRV2 的所有 BF16 轮次均达到该下限。这里的达标指带 profiling 的观测值，不等价于无 profiler CI 的复验。

## 3. 关闭绑核相对开启绑核

保持同一 CANN 和 Runner；变化 = 关闭 / 开启 − 1。MRV2 优先使用开启绑核的三轮均值，同时列出原始单轮基准，展示基准批次的影响。

| CANN | MRV1：关闭 / 原开启单轮 | MRV2：关闭 / 开启三轮均值 | MRV2：关闭 / 原开启单轮 |
| --- | ---: | ---: | ---: |
| 9.1.0 | +0.02% | **-0.20%** | +0.65% |
| 9.2.0 | +0.12% | **-0.67%** | -0.40% |

MRV1 基本持平；MRV2 的变化小于 1%，CANN91 的变化方向会随基准批次改变。**本轮没有观察到关闭绑核消除 CANN92 的性能差距。** 配置 enable_cpu_binding=false 同时跳过 CPU 绑定流程及其中的 NUMA 内存迁移，无法将观测变化拆成两者各自的纯效果。

## 控制条件与解释范围

- 沿用同一原 A2 测试主机和隔离四卡；固定 vLLM 0.30.0+empty（ced6857afa）与 vllm-ascend 0.19.1rc2.dev2433+gbbb5672af（bbb5672af），基础版本及同模型固定配置已核验。完整说明见 [环境核验与全部结果](README.md)。
- 所有 BF16 组都是 TP4、max-num-seqs=16、async scheduling、非 eager、FULL_DECODE_ONLY；同一模型权重和 GSM8K 正式客户端参数，内部预热 1 请求，正式 180 请求、失败 0、生成 270000 tokens。
- 每组新服务与独立编译缓存，稳定 decode 阶段采约 1 秒 profiling，四 rank 均完成解析。整轮吞吐包含 profiling 开关、导出及现场采样开销。
- 开启绑核批次在 2026-10-09 至 2026-10-10，关闭批次在 2026-10-14（Asia/Shanghai）。除 MRV2 开绑核三轮复测外，其他配置各仅一次；主机 CPU/IO、执行顺序及采样窗口状态不完全一致，关闭组还额外读取全部线程亲和性。因此这些百分比是观测差异，尚不能作为稳定因果收益。
